# Data1700-Oblig2

Formålet med oppgaven var å lage en enkel webapplikasjon for bestilling av kinobilletter, 
der brukeren kan registrere billetter og hente ut en oversikt over bestillingene.

## Funksjonalitet
- Registrere kinobilletter med informasjon om film, navn, antall billetter og kontaktinfo
- Validere brukerinput i frontend (JavaScript)
- Lagre billetter i backend (Java Spring Boot)
- Hente ut og vise registrerte billetter
- Enkel frontend med HTML, CSS og JavaScript
